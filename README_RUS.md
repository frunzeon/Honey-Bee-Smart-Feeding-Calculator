# Honey Bee Smart Feeding Calculator Shiny App

## Обзор

**Honey Bee Smart Feeding Calculator Shiny App** — это бесплатное интерактивное приложение на R Shiny, разработанное для помощи пчеловодам в расчёте потребности в сахарной подкормке и экономических затрат, связанных с зимовкой пчелиных семей.

Приложение поддерживает два вида пчёл:

- *Apis mellifera*
- *Apis cerana*

Программа позволяет оценить:

- общее количество корма для зимовки,
- необходимое количество сахара для приготовления 50% сахарного сиропа,
- предполагаемые затраты на сахар,
- предполагаемую стоимость замещения мёда.

Приложение предназначено для:

- практического пчеловодства,
- образовательных целей,
- планирования зимовки,
- экономической оценки.

---

## Научное обоснование

Успешная зимовка пчелиных семей в значительной степени зависит от достаточных кормовых запасов и силы семьи. Стратегии подкормки могут различаться в зависимости от климата, вида пчёл, местных традиций пчеловодства и условий окружающей среды.

Данное приложение было разработано как простой и прозрачный инструмент для оценки:

- потребности семей в корме,
- необходимости сахарной подкормки,
- экономической эффективности стратегий зимовки.

Калькулятор использует приблизительные практические коэффициенты, широко применяемые в пчеловодстве.

## Как использовать приложение

### Шаг 1 — Выбор вида пчёл

Выберите:

- A = *Apis cerana*
- B = *Apis mellifera*

### Шаг 2 — Ввод информации о семьях

Введите:

- количество рамок на семью,
- количество семей,
- цену сахара за кг,
- цену мёда за кг.

### Шаг 3 — Выполнение расчёта

Нажмите:

- Run calculation

Приложение рассчитывает:

- общий объём корма для зимовки,
- необходимое количество сахара,
- предполагаемые затраты на сахар,
- предполагаемую стоимость мёда.

### Шаг 4 — Просмотр результатов

Результаты отображаются в виде:

- таблиц,
- графиков.

## Коэффициент пересчёта сахара и мёда

В приложении используется приблизительный практический коэффициент:

1.5

Данный коэффициент может изменяться в зависимости от:

- силы семьи,
- состояния здоровья семьи,
- метода подкормки,
- температуры окружающей среды,
- сезонных условий.

---

## Ограничения

Программа предоставляет только приблизительные оценки.

Приложение не учитывает:

- региональные климатические различия,
- наличие медоносной базы,
- генетические особенности семей,
- состояние здоровья,
- паразитарную нагрузку,
- индивидуальную успешность зимовки,
- колебания рыночных цен,
- дополнительные затраты на содержание.

Результаты следует интерпретировать совместно с полевыми наблюдениями и местным опытом пчеловодства.

Кроме того, данное приложение не рекламирует и не продвигает сахарную подкормку как универсальную или лучшую стратегию пчеловодства. Методы подкормки должны подбираться с учётом местных условий, состояния семей, медоносной базы и региональных традиций пчеловодства.
